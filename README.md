# 📚 Primeiro Aporte

**Aprenda antes de investir.**

Guia educacional local que transforma conceitos financeiros em explicações simples e pequenas jornadas de aprendizagem.

## Diferenciais

- Três trilhas: primeiros passos, renda fixa e renda variável.
- Progresso por conceitos explorados.
- Ações “Explique de outro jeito” e “Ver um exemplo”.
- Verificação rápida de aprendizagem com feedback imediato.
- Sugestões de conceitos relacionados para continuar estudando.
- Tipografia acessível e áreas de interação ampliadas.
- Funcionamento exclusivamente local e sem APIs externas.

## Conteúdo

Responde dúvidas como “O que é investimento?”, “O que é CDB?” e “O que são fundos imobiliários?”, sempre apresentando funcionamento, pontos importantes, riscos e exemplos.

## Executar

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r src\requirements.txt
python -m streamlit run src\app.py
```

## Testar

```powershell
python -m pytest -q
```

Conteúdo educacional; não constitui recomendação de investimento.
